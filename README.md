🎹 Virtual Piano JS

Uma aplicação interativa de piano virtual desenvolvida inteiramente com HTML5, CSS3 e JavaScript Vanilla. O projeto permite tocar notas musicais diretamente pelo teclado do computador ou clicando nas teclas virtuais na tela.

🚀 Tecnologias Utilizadas

HTML5: Estruturação semântica dos elementos da aplicação.

CSS3: Estilização moderna, efeitos visuais nas teclas e layout responsivo.

JavaScript (ES6+): Manipulação do DOM, manipulação de áudio e captura de eventos de teclado/clique.

✨ Funcionalidades

🎵 Sons em tempo real: Reprodução instantânea das notas musicais.

⌨️ Mapeamento do Teclado: Suporte para tocar utilizando o teclado físico.

🖱️ Suporte a Clique/Toque: Clique nas teclas virtuais para reproduzir os sons.

🎨 Feedback Visual: As teclas destacam-se visualmente quando pressionadas.

📱 Design Responsivo: Adaptável para diferentes tamanhos de tela.
